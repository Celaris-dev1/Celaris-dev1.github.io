Gate

Verifies AI-written code before it merges.

  1. Install (detects your system automatically): 
    curl -fsSL https://celaris-dev1.github.io/download/gate/v0.1.0/gate-v0.1.0-$(uname -s | tr A-Z a-z)-$(uname -m | sed 's/x86_64/amd64/;s/aarch64/arm64/').tar.gz | tar xz
sudo mv gate /usr/local/bin/
  2. Activate your license: 
    gate license install PASTE-YOUR-KEY-HERE
gate license show

Proof

Signed evidence of what your crawler fetched and whether it was allowed to.

  1. Install: 
    npm install -g https://celaris-dev1.github.io/download/proof/v0.1.0/proof-0.1.0.tgz
  2. Activate your license: 
    proof license install PASTE-YOUR-KEY-HERE
