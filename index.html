Questions

What do I need to run it?

A computer (Mac, Windows or Linux) and an AI model key from a provider you choose. Prosper runs on your machine; the key is yours and you pay the provider directly.

Does every game work?

No. Prosper plays each build and repairs what it can. Complex physics, games with many scenes and 3D cameras fail most often. If a build still fails after repairs, Prosper stops and shows you what failed instead of calling it done.

Is 3D ready?

3D works but is still in progress. It is included in your plan and improves with each release.

Can I sell the games I make?

Yes. Each game is a normal project you own. Prosper uses only free-to-use art and sound, with a licence record for each file.

Is Prosper open source?

No. Prosper itself is closed. The games it builds are yours, with full source.
