How a build works

From brief to playable game

Every step is checked. A game only counts when a headless browser can actually play it.

  1. SpecTitle, genre, platform and description.
  2. DecomposeSystems, scenes, assets and glue.
  3. BuildModels write each unit, with fallbacks across providers.
  4. VerifyImports resolve, exports exist, scenes connect.
  5. MergeUnits bundle into one game.
  6. Play gateA headless browser boots it and reaches play.
  7. RepairAn agent fixes what fails until it passes.
